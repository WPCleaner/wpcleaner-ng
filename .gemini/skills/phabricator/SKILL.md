# Phabricator

Phabricator is the tool used by this project to manage bug reports and feature requests.
The homepage of this tool is available at [this URL](https://phabricator.wikimedia.org/).
The board dedicated to this project is available at [this URL](https://phabricator.wikimedia.org/project/board/4842/).

# Retrieve the content of a Phabricator issue

Phabricator issues are identified by letter `T` followed by a unique numeric identifier.
You can access a Phabricator issue by adding the identifier after the [base URL](https://phabricator.wikimedia.org/).
For example, if you want to access issue `T392773`, you can use [this URL](https://phabricator.wikimedia.org/T392773).
